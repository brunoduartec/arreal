# Pacote KDP de *Arreal*

Arquivos-fonte específicos da edição para Amazon KDP.

- `kdp_print.tex`: miolo da edição impressa, sem a capa.
- `kdp_structure.tex`: formato 5,5 x 8,5 polegadas, margens espelhadas e tipografia.
- `build_epub.py`: gera o EPUB refluível diretamente dos capítulos revisados.

Os capítulos originais em `chapters/` permanecem como fonte canônica do texto.
